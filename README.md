## 💡 The Problem & Solution

* **The Problem:** Traditional language learning feels like extra work and separates study from daily entertainment, leading to boredom and inconsistent practice. 
* **Our Solution:** AtheneumOfTongues³ solves this by letting users turn any media they already enjoy into personalized, interactive lessons featuring real-time translations, automated flashcards, and comprehension checks.

---

## ✨ Key Features

- 🎙️ **Voice AI Generation:** Powered by **ElevenLabs** to deliver natural, human-like voice synthesis.
- 🧠 **Smart Context Processing:** Leverages **Google Gemini API** for fast, high-accuracy reasoning and content transformation.
- ⚡ **Real-time Interaction:** Fast parsing and translation of media in a chosen language, and easily accessible implementation of reinforcement learning through flashcards and quizzes for phrases and words contained.

## 🚀 Quickstart & Local Setup

Follow these steps to run the project on your local machine.

### Prerequisites

* Python 3.9+
* API Keys for Google Gemini and ElevenLabs

---

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

---

### 2. Set Up Environment Variables

Create a file named .env in the root directory:
```bash
GEMINI_API_KEY=your_gemini_api_key_here
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
```

---

### 3. Install Dependencies & Run

For Python Backend:
```bash
python -m venv venv
source venv/bin/activate  (On Windows: venv\Scripts\activate)
pip install -r requirements.txt
python app.py
```

For Node / Frontend:
```bash
npm install
npm run dev
```
